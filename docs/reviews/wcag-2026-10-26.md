# Accessibility corrections — 2026-10-26

Scope: four findings from the local preview, corrected in the working tree based on `5bbaa36`. These results do not establish whole-site WCAG 2.2 AA conformance. No archived documentation source was edited.

## Corrections

1. **Mobile navigation / WCAG 2.4.11:** apply the existing dialog, background inertness, keyboard containment, Escape, and focus-return behavior on all routes instead of only the homepage. The regression fixture now covers home, docs, blog, and a project-prefixed Classic route.
2. **Image zoom / WCAG 2.1.1:** replace the registered mouse-only zoom plugin with a local client module. Meaningful, unlinked Markdown images become keyboard-focusable buttons with an accessible name containing their description. There is no new visible enlarge button or label. Enter and Space open a native modal dialog with the full-resolution image when available; Escape or its close control returns focus. Linked images retain their link behavior; decorative images remain noninteractive.
3. **Mobile Copy page / WCAG 4.1.2:** keep the plugin's text visually clipped rather than `display: none` below 768px. Its icon-only presentation retains the accessible name “Copy page”. The override is scoped through the plugin's custom button class.
4. **Search contrast / WCAG 1.4.3:** override the theme's placeholder colors with sufficient specificity. Light mode uses `#625d54` against `#f3f4f6` (5.94:1); dark mode uses `#aeb6c3` against `#1f2937` (7.19:1). The focused backgrounds provide 6.54:1 and 8.68:1 respectively.

## Validation

- `pnpm test`: **27/27 pass**.
- `pnpm run check:content`: **182 documents pass**, including sidebar, local-link, image, anchor, and redirect checks.
- `git diff --check`: **pass**.
- Browser: Chrome on macOS, local development preview at `http://127.0.0.1:3001/`, default desktop viewport and 320 × 800 CSS pixels. Root base URL, local search, light and dark themes. This preview uses a separate generated-files directory and does not replace the existing port-3000 server.
- `/docs/`: Enter and Space activate the described image trigger. The native dialog exposes “Enlarged image”, “Close enlarged image”, and the image description. Escape returns focus to the image. The full-resolution source loads at 1764 pixels wide in the tested example. The adjacent linked thumbnails remain links.
- `/docs/`, 320px: Copy page remains named in the browser accessibility representation while its text is visually clipped. Opening navigation focuses its close control; the main content and underlying navbar have `inert`; Shift+Tab/Tab stay in the drawer; Tab from the final FAQ control wraps to the drawer's brand link; Escape restores focus to the navigation trigger.
- `/blog/`, 320px: navigation from the docs drawer reaches the blog and closes the drawer. Reopening it exposes a dialog, focuses its close control, and makes the page background inert.
- `/docs/`: computed placeholder/background colors match the light and dark values above after theme transitions finish. Ratios use the WCAG relative-luminance formula.

The initial isolated preview attempt could not bind a local socket under the sandbox (`EPERM`); Docusaurus's port detection exhausted memory while retrying. A one-time elevated local preview resolved the environment restriction. This was not an application failure.

## Limits

No production build or deployment was run. David Schargel did a smoke test on multiple pages via VoiceOver on macOS Golden Gate in Safari. Other VoiceOver/Safari and NVDA/Firefox speech output, the full route/zoom/text-spacing matrix, and embedded video captions/audio description remain unverified. Browser accessibility names are supporting evidence, not a substitute for those checks. Package versions and third-party notices are unchanged; the old zoom package is no longer registered in the site configuration.
