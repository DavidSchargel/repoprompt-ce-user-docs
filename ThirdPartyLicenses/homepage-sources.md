# Homepage dependency notice sources

This records the sources of the preserved license files. Package versions are
tracked in `package.json` and `pnpm-lock.yaml`.

| Preserved file | Source |
| --- | --- |
| [react-icons/LICENSE](react-icons/LICENSE) | `node_modules/react-icons/LICENSE`; includes package MIT text and notices for the icon sets it distributes. |
| [react-tweet/license.md](react-tweet/license.md) | `node_modules/react-tweet/license.md`; copyright (c) 2023 Luis Alvarez. |
| [feather/LICENSE](feather/LICENSE) | [Feather v4.29.1 LICENSE](https://raw.githubusercontent.com/feathericons/feather/v4.29.1/LICENSE). |
| [font-awesome/LICENSE.txt](font-awesome/LICENSE.txt) | [Font Awesome LICENSE.txt at afecf2a](https://raw.githubusercontent.com/FortAwesome/Font-Awesome/afecf2a/LICENSE.txt). |
| [font-awesome/CC-BY-4.0.txt](font-awesome/CC-BY-4.0.txt) | [Creative Commons Attribution 4.0 International legal text](https://creativecommons.org/licenses/by/4.0/legalcode.txt). |

The installed `react-icons/lib/iconsManifest.js` and `react-icons/README.md`
identify Feather as MIT and Font Awesome icons as CC BY 4.0. Other icon sets
listed in the package's license file are not thereby identified as used by this
site. Recheck source imports when updating this inventory.
