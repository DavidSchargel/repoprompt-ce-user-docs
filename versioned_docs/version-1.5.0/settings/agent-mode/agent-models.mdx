Choose the Oracle analysis model, the Context Builder agent and model, and model defaults for sub-agent roles such as Pair, Design, Explore, and Engineer.

</div>

</div>

Open **Settings → Agent Mode → Agent Models**.

1. If a workspace is open, choose **Use global settings** or **Use workspace overrides** to select where your model changes apply.
2. Open the **Oracle Model** picker and select the analysis model. Under **Context Builder Agent**, open the agent/model menu and choose the connected CLI agent and model that will gather context. If none is connected, use **Connect in CLI Providers** first.
3. In **Sub-Agent Role Defaults**, open each role's menu and choose its agent and model: **Pair** for primary work, **Design** for interface and copy work, **Explore** for investigation, and **Engineer** for implementation.
4. To return the role mappings to the suggested configuration, click **Reset All to Recommended**.
