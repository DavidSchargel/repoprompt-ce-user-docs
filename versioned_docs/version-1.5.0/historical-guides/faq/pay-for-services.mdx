Understanding the difference between the free Repo Prompt application and optional AI-provider costs.

## Application and AI Provider Costs

:::tip

**Important:** Repo Prompt Community Edition is free and open source. Charges may still apply when you use paid third-party AI providers.

:::

### AI Provider Costs

Repo Prompt does **not** bundle paid AI service. Instead, you bring your own API keys and pay providers directly based on your actual usage:

#### Supported AI Providers (15+)

- **OpenAI:** GPT-5.4 family - pay per token directly to OpenAI
- **Anthropic:** Claude Sonnet 4.5, Claude Opus 4, Claude Haiku 4.5 - pay per token directly to Anthropic
- **Google:** Gemini 3.0 Preview, Gemini 3.0 Flash - pay per token directly to Google
- **Codex CLI (OpenAI Plus/Pro subscription):** GPT-5.5 Low/Medium/High are covered by your Codex/OpenAI subscription, separately from API-key token billing. This is the recommended way to use GPT-5.5 inside Repo Prompt.
- **ChatGPT Pro (web):** GPT-5.5 Pro is available through your ChatGPT Pro subscription for architectural planning via the ChatGPT Export workflow — it is not an API/OpenRouter model.
- **OpenRouter:** Access to 100+ models with unified billing
- **Azure OpenAI:** Enterprise-grade access with Microsoft billing
- **GitHub Models:** Free tier available with GitHub account
- **DeepSeek, Grok, Fireworks:** Alternative providers with competitive pricing
- **Ollama:** Run local models completely free
- **Custom Endpoints:** Connect to any OpenAI-compatible API

## Cost Control & Transparency

### Why This Model Benefits You

- **No Markup:** Pay AI providers directly at their native rates with no Repo Prompt markup
- **Usage-Based:** Only pay for the AI tokens you actually use, not a monthly AI allocation
- **Provider Choice:** Switch between providers based on cost, capability, or availability
- **Free Options:** Use GitHub Models free tier or run local Ollama models at no AI cost
- **Enterprise Control:** Use your organization's existing AI provider contracts

### Built-in Cost Management

Repo Prompt includes several features to help manage AI costs:

- **Real-time Token Counting:** See exact token usage before sending requests
- **Code Maps:** Reduce token usage by 60-80% while maintaining context quality
- **Context Builder:** Intelligent file selection to minimize unnecessary tokens
- **Model Selection:** Choose appropriate models for different tasks (e.g., cheaper models for simple tasks)
- **Rate Limit Management:** Automatic throttling to prevent unexpected charges

## Getting Started with AI Providers

### Free Options to Try

1. **GitHub Models:** Connect your GitHub account for free access to several models
2. **Google Gemini:** Free tier available with generous monthly limits
3. **OpenRouter:** Offers free credits and access to free models
4. **Ollama:** Run models locally on your machine (completely free, no internet required)

### For Production Use

1. Choose your preferred AI provider(s) based on model quality, cost, and requirements
2. Sign up directly with the provider and obtain API keys
3. Add your API keys to Repo Prompt settings
4. Pay the provider directly based on your usage

## Example Cost Scenarios

:::tip

**Typical Usage:** AI-provider costs depend on the models, subscriptions, and API usage you choose. Repo Prompt does not add a markup.

:::

### Context Builder & Chat Mode Costs

When using Repo Prompt's built-in AI features:

- **Context Builder:** Analyzes your codebase to recommend files - uses tokens based on project size and complexity
- **Chat Mode:** Direct AI conversations within Repo Prompt - costs depend on conversation length and model choice
- **Pro Mode:** Advanced multi-model workflows - uses multiple models optimized for different tasks

All usage is transparent with real-time token counting, and you maintain full control over costs by choosing models and managing context size.

## No Lock-in, Maximum Flexibility

This separation of app and AI costs means:

- You can use Repo Prompt's powerful context building even with free AI models
- Upgrade or downgrade AI providers without affecting your Repo Prompt functionality
- Take advantage of AI provider competition and pricing improvements
- Use different models for different purposes (e.g., fast/cheap models for file analysis, premium models for complex coding)
