## Community Edition Version 1.x Series

The Community Edition 1.x series is the first release in the Community Edition series. RepoPrompt CE is a native macOS app for orchestrating coding agents with a focus on context engineering. It builds an agent harness around an MCP server, giving you a shared place to prepare repository context, connect compatible CLI agents, run focused tasks, and inspect the work they produce. The goal is simple: make it easier to give agents the right context and keep multi-step engineering work understandable.

### Key Features in Community Edition 1.x

- Native macOS workspace for context engineering and agent orchestration.
- MCP-based harness for integrating compatible CLI agents.
- Repository-aware context selection, search, diffs, and worktree workflows.
- Public Sparkle update channel for signed, notarized releases.
- Fully open source and free to use.
