One of RepoPrompt's core features is the ability to selectively include files for context when working with AI models. This helps optimize token usage and improves the quality of AI responses.

## Selecting Files and Folders

1. In the file tree panel, browse to the files or folders relevant to your current task
2. Click the checkbox next to a file name to select it (the content will be included in the prompt)
3. Click the checkbox next to a folder name to select all files within that folder (including subfolders)
4. Selected files will appear as cards in the "Selected Files" panel on the right side
5. Deselect items by unchecking their corresponding checkboxes

## Drag and Drop

For quick file selection from your system:

- Drag files or folders from Finder/Explorer directly onto the RepoPrompt window
- Dropped items will be added to your workspace and automatically selected

## Selection Best Practices

- **Be selective:** Only include files directly relevant to your query
- **Watch token limits:** Monitor the token count at the bottom of the window
- **Include related files:** Add interface/type definition files that help understand structure
- **Consider Code Maps:** For large files, consider using Code Maps instead of full content

:::tip

**Tip:** Selecting only the most relevant files not only saves tokens but also improves the focus and quality of the AI's response by reducing noise. For complex tasks, prioritize including files that define core interfaces or types first.

:::
