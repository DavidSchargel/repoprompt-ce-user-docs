The search function in RepoPrompt helps you quickly locate specific files in large workspaces.

## Basic Search

1. Locate the "Search files" input box above the file tree panel
2. Type your search query (e.g., a file name or part of it)
3. The file tree will dynamically filter to show only matching files and their parent folders
4. Clear the search box to restore the full file tree view

## Advanced Search Patterns

RepoPrompt supports pattern-based searching:

- **Wildcards:** Use `*` to match any sequence of characters

  - Example: `*.css` shows only CSS files
  - Example: `*.test.*` might find test files with any extension
- **Basic Regex:** Use regular expression patterns for more complex searches

:::tip

**Tip:** Combine searching with filtering to quickly isolate the specific files you need for your prompt context.

:::
