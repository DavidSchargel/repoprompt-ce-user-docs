RepoPrompt offers flexible sorting options for both the main file tree and your selected files.

## Sorting the File Tree

1. Locate the "Sort" button in the toolbar above the file tree panel
2. Click the "Sort" button to open a dropdown menu
3. Choose your desired sorting criteria:

   - **Name (A-Z or Z-A):** Alphabetical sorting by file name
   - **Extension (A-Z or Z-A):** Group files by their type/extension
   - **Date (Newest or Oldest):** Sort by modification date

## Sorting Selected Files

1. In the "Selected Files" panel on the right, locate the "Sort" button
2. Click this "Sort" button to choose how the selected file cards are ordered:

   - **Name (A-Z or Z-A):** Alphabetical sorting by file name
   - **Tokens (Low-High or High-Low):** Sort by token usage

## Changing Selected Files View

Next to the "Sort" button in the Selected Files panel, there are view toggle buttons:

- **Folder icon:** Group selected files by their parent folders
- **File list icon:** Show all selected files in a flat list

:::tip

**Tip:** Sorting by tokens is particularly useful for optimizing context size when working with token-limited LLMs.

:::
