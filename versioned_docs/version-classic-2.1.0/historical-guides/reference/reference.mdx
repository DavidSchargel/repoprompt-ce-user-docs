## Model Recommendations

### Fast & Affordable

- **Gemini 2.5 Flash:** Excellent speed/quality, diff-capable
- **GPT-5 Mini:** Fast, good for simple edits
- **DeepSeek Chat:** Very cheap with strong diff support

### Complex Coding & Reasoning

- **GPT-5.5 High (Codex CLI):** Best all-around in-app coding and reasoning model in our current testing
- **GPT-5.5 Pro (ChatGPT Pro web):** Best for deep planning and high-value reasoning sessions
- **Claude Opus 4.6:** Still excellent for editing-heavy work and UI polish
- **Grok 4:** Capable alternative with diff support

### Best Overall Value

- **GPT-5.5 Low/Medium (Codex CLI):** Best value split for explore and Context Builder/discovery (Low) plus engineer/default implementation (Medium) if you already use Codex CLI via ChatGPT Plus/Pro
- **Claude Sonnet 4.5:** Reliable, diff-capable, great for quick fixes
- **Gemini 3 Pro Preview:** Strong performance with speed

Our current recommendation is to center your setup on OpenAI Plus/Pro so you can run GPT-5.5 Low/Medium/High via Codex CLI and GPT-5.5 Pro on ChatGPT Pro web. If you want Claude Code as a secondary option, Claude Pro is usually enough for light UI work and fast fixes.

:::tip

**GPT-5.5 availability:** GPT-5.5 Low, Medium, and High are Codex CLI-only, and GPT-5.5 Pro is ChatGPT Pro web only. GPT-5.5 is not offered through the OpenAI API, Azure OpenAI, or OpenRouter — those continue to serve GPT-5.4.

:::

## Keyboard Shortcuts

| --- | --- |
| `⌘+C` | Copy prompt to clipboard |
| `⌘+N` | Start new AI chat |

| `⌘+F` | Search files |
| `⌘+,` | Open Settings |
