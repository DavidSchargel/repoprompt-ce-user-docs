After opening a workspace, the panel on the left displays your project's file structure.

## Basic Navigation

- Click the arrow icons (▶︎/▼) or on the folder name itself to expand or collapse a folder
- Files within folders are displayed with appropriate file type icons
- Use the scrollbar to move through larger file structures

## Folder Structure

The file tree displays a hierarchical view of your project, similar to what you'd see in your system's file explorer or IDE:

- Root folder (your workspace)
- Subfolders (nested according to your project structure)
- Files (shown within their parent folders)

This familiar tree structure makes it easy to locate specific files or understand the organization of your project.
