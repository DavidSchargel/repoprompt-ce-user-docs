RepoPrompt allows you to open multiple folders simultaneously, which is useful when working with related projects, referencing documentation, or including external libraries.

## Adding Another Folder

1. With a workspace already open, locate the toolbar above the file tree panel
2. Click the folder icon button ("**Open a new folder**") in this toolbar
3. Use the system dialog to select another folder you wish to add
4. The newly added folder will appear as another root item in the file tree panel

## Use Cases for Multiple Folders

- **Related Projects:** Include both a frontend and backend repository
- **Documentation:** Add a documentation folder alongside your code
- **External Libraries:** Reference library source code while working on your project
- **Package Dependencies:** Include package source code for better AI context

:::tip

**Tip:** You can select files from any of the open folders to include in your prompt, allowing you to provide the AI with a more complete picture of your codebase.

:::
