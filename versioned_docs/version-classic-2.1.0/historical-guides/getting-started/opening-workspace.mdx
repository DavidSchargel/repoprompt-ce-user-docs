The first step in using RepoPrompt is opening a workspace containing the code files you want to work with.

## Opening a Project Folder

When you launch RepoPrompt, you'll see the main interface with the "Workspaces" section on the left:

1. Click the "**Open Folder**" button to browse for a project directory
2. Navigate to your desired project folder in the system dialog that appears
3. Select the folder and click "Open"

## Using Recent Workspaces

For folders you've previously opened:

1. Look for the folder name in the "**Recent workspaces**" list
2. Click the workspace name to open it directly

Once opened, the folder's name will appear as the root in the file tree panel on the left, and its contents will be displayed below it.

:::tip

**Tip:** RepoPrompt remembers your workspace settings (selected files, active prompts, etc.) between sessions if you save your workspace.

:::
