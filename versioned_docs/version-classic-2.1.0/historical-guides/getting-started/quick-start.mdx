Get from download to your first AI prompt in under 5 minutes.

## 1. Install RepoPrompt

- **Mac App Store:** Search "RepoPrompt" or visit [the App Store listing](https://apps.apple.com/app/repo-prompt/id6720712141)
- **Direct Download:** Get the latest version from [repoprompt.com](https://repoprompt.com)

## 2. Open Your First Workspace

1. Launch RepoPrompt
2. Click **Open Folder** or drag a project folder onto the window
3. Your file tree appears in the left sidebar

:::tip

**Multi-Root Workspaces:** You can add multiple folders to analyze related projects together. Use File → Add Folder or drag additional folders.

:::

## 3. Select Files for Context

Click checkboxes next to files you want to include. The token count updates in real-time.

**Selection modes** (Pro feature for slices/codemaps):

- **Full:** Complete file content (default)
- **Slices:** Specific line ranges only
- **Codemap:** Just function/type signatures - 10x token savings

## 4. Copy Your First Prompt

1. Write instructions in the prompt area (or use a preset)
2. Click **Copy**
3. Paste into ChatGPT, Claude, or any AI

That's it! Your prompt includes your files, instructions, and formatting that helps AI understand your codebase.

## 5. (Optional) Set Up AI Integration

### Option A: CLI Providers (Use Existing Subscriptions)

If you have Claude Pro/Max, ChatGPT Plus/Pro, or Google AI - use those subscriptions in RepoPrompt:

1. Go to Settings → CLI Providers
2. Connect your provider (requires CLI tool installed and logged in)
3. Use Chat mode without API costs

### Option B: API Keys

For direct API access:

1. Go to Settings → API Keys
2. Add keys for OpenAI, Anthropic, Google, etc.
3. Select models in Chat mode

## What's Next?

- **Try Chat mode:** Have AI conversations with your code context
- **Explore Pro Edit:** Let AI edit multiple files with professional diff review
- **Set up MCP:** Use RepoPrompt with Claude Code or Cursor
