## Free and Open Source

RepoPrompt Community Edition is free and includes:

- Access to all core features with a 32k token limit for copying and chatting
- The ability to connect to your own AI providers (OpenAI, Anthropic, etc.) with your API keys
- Full file selection, workspace management, and Apply Mode capabilities

The 32k token limit is sufficient for most use cases, as model response quality tends to degrade beyond this limit. If you find yourself hitting this limit frequently, consider being more selective with your file choices to create more focused and effective prompts.

Download the latest Community Edition release:

- Visit the [latest GitHub release](https://github.com/repoprompt/repoprompt-ce/releases/latest)
- Download the macOS build and follow the installation instructions
- Visit the [source repository](https://github.com/repoprompt/repoprompt-ce) to contribute

:::tip

**Tip:**

Focus on selecting the files most relevant to your task. Smaller, intentional context often produces more precise AI responses.

:::
