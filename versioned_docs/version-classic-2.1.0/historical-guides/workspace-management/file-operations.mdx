RepoPrompt provides several ways to interact with files beyond just selecting them for prompts.

## Previewing File Content

To quickly examine a file's content without selecting it:

1. In the "Selected Files" panel on the right, hover over a file card
2. Click the magnifying glass icon that appears
3. A modal window will pop up showing the content of that file
4. Close the preview by clicking outside the modal or using its close button

## File Context Menu

Right-clicking on any file or folder in the main file tree provides access to additional operations:

- **Copy:** Copies the file's content to your clipboard
- **Reveal in Finder/Explorer:** Opens the file's location in your system's file explorer
- **Copy Relative Path:** Copies the file's path relative to the workspace root
- **Copy Full Path:** Copies the file's absolute path on your system
- **Select All Children:** (For folders) Selects all files within the folder
- **Deselect All Children:** (For folders) Deselects all files within the folder

## Working with Multiple Files

The file context menu also enables batch operations:

- Right-click on a folder and use "Select All Children" to quickly include all files
- Use "Deselect All Children" to remove all files in a folder from your selection
- Hold Shift while checking boxes to select consecutive files

:::tip

**Tip:** The "Copy Relative Path" option is particularly useful when you want to explicitly reference a file in your prompt instructions.

:::
