RepoPrompt allows you to save and manage workspaces, preserving your setup of open folders, selected files, instructions, and active prompts between sessions.

## Workspace Management Options

The name of the currently open workspace is displayed in a dropdown menu at the top center of the window. Click this dropdown to access workspace management options:

## Saving a Workspace

1. Set up your workspace with the desired folders, file selections, and prompts
2. Click the workspace name dropdown at the top center
3. Select "Save Workspace" to preserve the current state
4. Your workspace configuration will be saved locally

## Switching Between Workspaces

1. Click the workspace name dropdown
2. Select a previously saved workspace from the list
3. RepoPrompt will load that workspace configuration, including open folders, selected files, and active prompts

## Closing a Workspace

To save and close the current workspace:

1. Click the workspace name dropdown
2. Select "Save & Exit Workspace"
3. This will save the current state and return you to the initial screen

## Managing Specific Folders

To close a specific root folder within the current workspace:

1. Locate the folder in the file tree panel
2. Click the "X" button next to its name
3. The folder will be removed from the current workspace, but the workspace itself will remain open

## Advanced Workspace Management

1. Click the workspace name dropdown
2. Select "Manage Workspaces..."
3. A modal will appear allowing you to rename, duplicate, or delete saved workspaces

:::tip

**Tip:** Create separate workspaces for different projects or tasks to quickly switch between them without losing your carefully curated file selections and prompts.

:::
