RepoPrompt automatically monitors your workspace folders for changes, ensuring the file tree always reflects the current state of your project.

## Automatic File System Watching

With file watching, RepoPrompt detects and reflects the following changes automatically:

- **File additions:** New files appear in the file tree
- **File deletions:** Removed files disappear from the tree
- **File modifications:** Changed files are updated in selections
- **Renames:** Renamed files are updated in the file tree
- **Folder structure changes:** Moved or new folders are reflected

## Benefits of File Watching

- Seamlessly work between RepoPrompt and your code editor
- No need to manually refresh when files change
- Always work with the most current version of your code
- Changes made through the AI's suggestions are immediately available for next prompts

## Manual Refresh

While rarely needed due to automatic watching, a manual refresh option is available:

1. Locate the "Refresh" button (circular arrow icon) above the file tree
2. Click this button to force RepoPrompt to rescan your workspace folders
