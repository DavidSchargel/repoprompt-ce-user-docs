RepoPrompt's stored prompts feature allows you to save and reuse system prompts to guide the AI's role and output format.

## Understanding Stored Prompts

Stored prompts in RepoPrompt are reusable system messages that:

- Provide consistent instructions to the AI across different sessions
- Define specific AI roles (like the built in "Architect" or "Engineer")
- Structure the AI's output format for better consistency
- Can be combined with your specific instructions

## Using Stored Prompts

1. Active stored prompts appear above the instructions text box.
2. Hover over a prompt tab to preview its content
3. Active prompts will be prepended to your instructions in the "Meta prompts" section when generating the final prompt

## Managing Stored Prompts

1. Click the "Prompts" button on the far right of the prompt tab bar
2. A dropdown list appears with available prompts
3. Clicking on a prompt will toggle it
4. Use the "Create New" or "Edit" options to manage your prompt library
5. You can import and export stored prompts from the advanced settings menu, using a bespoke json format.

## Creating Custom Prompts

To create a new stored prompt:

1. Click the "Prompts" button and select "Create New"
2. Enter a name for your prompt (e.g., "Code Reviewer")
3. Write the prompt content in the editor
4. Save your new prompt to make it available in the prompts list

:::tip

**Tip:** Create specialized prompts for different tasks, such as code review, architecture planning, bug fixing, or feature implementation to maintain consistency across similar AI interactions.

:::
