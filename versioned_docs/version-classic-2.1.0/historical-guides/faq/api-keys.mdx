Common questions about using API keys with RepoPrompt.

## Security

Your API keys are stored securely on your local machine. They are never transmitted anywhere except directly to the respective API provider during requests.

## Adding/Removing Keys

Manage your API keys in the RepoPrompt settings panel.

## Multiple Keys

You can add keys for multiple supported API providers.
