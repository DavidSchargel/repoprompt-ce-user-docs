Information regarding the availability of RepoPrompt on Windows and Linux platforms.

## Current Status

RepoPrompt is currently only available for macOS.

## Future Plans

This is something being considered, but Repo Prompt is a native macOS app, which means it is built with deep mac native API integration. This is important for performance reasons (large repositories can tax your app quite easily), and also because file systems between operating systems require a lot of careful consideration. The current near term priority remains to support the mac version, but you can join the waitlist to be notified if platform availability changes:
