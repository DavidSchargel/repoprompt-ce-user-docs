## Classic Edition Version 1.5 Series

The Classic Edition 1.5 series introduces Background Mode with menu bar control, tab-bound chats with concurrent streaming, Context Builder 2.0 with agentic discovery and auto plan generation, compose tabs for parallel workflows, interactive CLI, and support for new CLI providers.

### Key Features in 1.5

- **Integrated Sidebar Terminal** - Launch terminal sessions directly in the sidebar with support for AI agent CLIs or a plain shell
- **Background Mode** - App stays active when windows are closed, with a menu bar icon for quick restore or quit
- **Tab-Bound Chats** - Chats are now bound to tabs for easier session management, with support for multiple concurrent streaming conversations
- **Interactive CLI** - Command-line interface for MCP tools with shell aliases, command history, output redirection, exec mode, and one-click PATH installation
- **Context Builder 2.0** - Agentic context building using Claude Code or Codex to automatically select files, codemaps, and slices within a token budget
- **Auto Plan Generation** - Context builder can automatically generate an implementation plan after exploration
- **Discovery Clarifying Questions** - Agent can ask clarifying questions during context building for better results
- **Reasoning Display** - See the model's thought process during plan generation in a collapsible section
- **Compose Tabs** - Work on multiple tasks in parallel with independent prompts and file selections per tab
- **Pro Edit Agent Mode** - Use Claude Code or Codex with MCP tools to generate edits in parallel with higher accuracy
- **Claude Code Slash Commands** - One-click installation of Repo Prompt MCP commands from settings
- **MCP Builder Preset** - Four-phase workflow: quick scan, context building, chat refinement, and implementation
- **UNIX Socket MCP Transport** - Replaced network communication for better performance, no Local Network permission needed
- **Codex CLI as API Provider** - Use OpenAI models through your Plus or Pro plan via Codex CLI
- **Gemini CLI Support** - Use Gemini CLI for chat, discovery & delegate edits
- **Context Builder as MCP Tool** - Run discovery directly from external agents
- **Tab Management via MCP** - Control tabs and workspaces programmatically
- **GPT-5.2 & Opus 4.5 Support** - Latest OpenAI and Anthropic models with extended reasoning variants
- **Chat Message Forking** - Edit user messages to create conversation branches
- **Model Recommendation Engine** - Automatic model suggestions based on your current workflow and configuration
- **File Actions** - Open files in default apps, copy absolute paths, and reveal in Finder from file tree
- **Prompt Export** - Export complete clipboard content to a file via MCP tool, plus ChatGPT Prompt Export command for generating prompt files for GPT Pro models
