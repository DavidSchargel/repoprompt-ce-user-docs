## Classic Edition Version 2.1 Series

The Classic Edition 2.1 series introduces MCP-controlled agents and cross-family sub-agents, allowing external MCP clients to start and steer Agent Mode sessions, and enabling agents to delegate work across CLI families.

### Key Features in 2.1

- **MCP-Controlled Agents** - Start and steer Agent Mode sessions from external MCP clients or the CLI via the new agent\_run and agent\_manage tools
- **Cross-Family Sub-Agents** - Within Agent Mode, spin up sub-agents across different CLI families — Claude can steer Codex, Codex can steer Claude
- **Agent Role Defaults** - Configure default models per agent role (explore, engineer, pair, design) with per-role override controls
- **Cleaner MCP API** - Dedicated manage\_selection and prompt tools replace context\_state; chat tools renamed to oracle; new context\_bind for easy workspace binding via working directories
