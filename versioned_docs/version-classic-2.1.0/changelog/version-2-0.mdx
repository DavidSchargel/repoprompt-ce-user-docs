## Classic Edition Version 2.0 Series

The Classic Edition 2.0 series introduces RepoPrompt Agent, a fully integrated agent harness that brings interactive, agentic coding sessions directly into the app with first-class support for Codex, Claude Code, and Gemini.

### Key Features in 2.0

- **RepoPrompt Agent** - A completely new way to use RepoPrompt with interactive, agentic coding sessions powered by your choice of AI provider
- **Full Native Codex Support** - Rich integration with the Codex app server for the best agent experience, including configurable tool preferences and reasoning effort
- **Claude Code & Gemini Support** - Interactive agentic sessions via headless CLIs, with full native reasoning traces, steering, bash tool calls, and approval flows
- **Context Builder Integration** - Agents can leverage RepoPrompt's context building workflows for deeper codebase understanding
- **Optional Edit Review** - Review and approve each edit the agent makes before it's applied
- **Agent Onboarding** - Guided wizard for setting up Agent Mode, including license activation, provider testing, and MCP server configuration

A completely new way to use RepoPrompt. RepoPrompt Agent is a fully integrated agent harness that brings interactive, agentic coding sessions directly into the app.

- **Full native support for Codex** - Rich integration with the Codex app server for the best agent experience
