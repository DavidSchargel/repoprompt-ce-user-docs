Connect directly to AI providers using API keys. This gives you full control over model selection and usage.

:::tip

**IDE Mode only (Classic Edition):** API key providers power Chat, Context Builder, Oracle, and Pro Edit. Agent Mode requires a CLI harness — RepoPrompt supports [six compatible CLIs](../../version-1.6.0/agent-mode/providers.mdx) including Codex, Claude Code, Gemini, OpenCode, and Cursor.

:::

:::tip

**GPT-5.5 is not an API model:** GPT-5.5 Low/Medium/High are available only through Codex CLI, and GPT-5.5 Pro is ChatGPT Pro web only. The OpenAI API and Azure OpenAI continue to serve the GPT-5.4 family. Use Codex CLI (under [Agent Providers](../../version-1.6.0/agent-mode/providers.mdx)) to access GPT-5.5.

:::

## Supported Providers

RepoPrompt supports direct API connections to these providers:

| Provider | Models | Context |
| --- | --- | --- |
| **Anthropic** | Claude Opus 4.6, Sonnet 4.5, Haiku 4.5 | 200K |
| **OpenAI** | GPT-5.4 family | 1M+ |
| **Google** | Gemini 2.5 Pro, Gemini 2.5 Flash | 1M+ |
| **DeepSeek** | DeepSeek V3, DeepSeek R1 | 128K |
| **xAI** | Grok 4 | 128K |
| **Groq** | Llama, Mixtral (fast inference) | Varies |
| **Fireworks AI** | Qwen3, Kimi K2, DeepSeek | Up to 32K |
| **Z.AI** | GLM 4.6, GLM 4.7, GLM 5 | 200K |
| **Azure OpenAI** | Your Azure deployments | Varies |

## Adding API Keys

1. Open **Settings** (`⌘+,`)
2. Go to **API Settings → API Providers**
3. Find your provider and enter your API key
4. Click **Validate & Save**
5. A green checkmark confirms the key is valid

## Getting API Keys

### Anthropic (Claude)

1. Go to [console.anthropic.com](https://console.anthropic.com/settings/keys)
2. Create an account or sign in
3. Navigate to Settings → API Keys
4. Create a new key and copy it

### OpenAI (GPT)

1. Go to [platform.openai.com](https://platform.openai.com/api-keys)
2. Create an account or sign in
3. Navigate to API Keys
4. Create a new secret key and copy it

### Google (Gemini)

1. Go to [aistudio.google.com](https://aistudio.google.com)
2. Sign in with your Google account
3. Get your API key from the console

## Key Security

Your API keys are stored securely in the macOS Keychain - they never leave your machine and are encrypted at rest.

## Custom Models

For providers that support it, you can add custom model names:

1. After validating your API key, look for the "Custom Model" field
2. Enter the model identifier (e.g., `claude-3-5-sonnet-latest`)
3. Click "Save Model"
4. The model appears in your model selection dropdown

For OpenAI custom models using the Responses API, you can also configure reasoning effort levels (low, medium, high) to control how much thinking the model does before responding.

## GitHub Models (Free)

GitHub provides free access to select models with an 8K context limit:

1. Go to Settings → API Providers
2. Click "Sign in with GitHub"
3. Authorize RepoPrompt
4. GitHub models appear in your model list

:::tip

**Note:** GitHub models are limited to 8K tokens context, which may be too small for many coding tasks. Consider using other providers for larger contexts.

:::

## Local Models (Ollama)

Run models locally with Ollama:

1. Install Ollama from [ollama.com](https://ollama.com)
2. Pull a model: `ollama pull llama3.1`
3. In Settings → API Providers, find "Local Model Settings"
4. The default URL is `http://localhost:11434`
5. Click "Validate" to fetch available models
6. Select your model from the dropdown
