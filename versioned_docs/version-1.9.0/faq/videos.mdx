Yes. Start with a guided walkthrough, choose a topic from the **RepoPrompt 101** playlist, or watch the **Rate Limited** podcast for broader discussions about AI-assisted coding.

:::warning[The software is way past this recording]
Many of these videos and podcast episodes are several months old (if not longer), and RepoPrompt has come a long way since they were recorded. The fundamentals remain useful, but the recordings include Classic Edition interfaces, earlier workflow names, and older model releases. Use them to understand the ideas and see examples, then follow [Getting Started](../overview/getting-started.mdx), [Going Deeper](../overview/going-deeper.mdx), and [Providers & Models](../providers/overview.mdx) for current instructions, controls, and supported connections.
:::

## Start with a guided walkthrough

**[Ray Fernando: Repo Prompt — Why Is Nobody Talking About This?](https://www.youtube.com/watch?v=G8TLeEdcdAM)** · About 11 minutes

Ray takes a project through setup and a refactoring workflow. The demonstration shows repository exploration, planning, and concurrent implementation agents working through connected coding runtimes. Watch this when you want to see how the pieces fit together before trying your own task.

:::tip[Learn the flow, then follow the current guide]
This walkthrough is several months old. RepoPrompt's setup and workflows have developed substantially since then, so follow the current installation guide for the exact steps while using the video to learn the overall flow.
:::

Useful places to jump in:

- [0:57 — Setup wizard](https://www.youtube.com/watch?v=G8TLeEdcdAM&t=57s): connect the tools used in the demonstration.
- [3:34 — Refactoring a project](https://www.youtube.com/watch?v=G8TLeEdcdAM&t=214s): move from setup to a concrete coding task.
- [5:03 — Repository exploration](https://www.youtube.com/watch?v=G8TLeEdcdAM&t=303s): see how the discovery stage gathers context.
- [8:38 — Concurrent implementation](https://www.youtube.com/watch?v=G8TLeEdcdAM&t=518s): follow more than one coding agent working on the task.

For the written path, start with [Installation](../overview/installation.mdx), then complete the four steps in [Getting Started](../overview/getting-started.mdx).

## Watch or listen to Rate Limited

**[Rate Limited on YouTube](https://www.youtube.com/@ratelimitedpod)** brings together Eric Provencher, Ray Fernando, and Adam Larson, also known as Gosu Coder, for discussions about AI-assisted coding.

Choose this for longer conversations about how developers use agents, rather than a step-by-step RepoPrompt lesson. Topics include:

- **Working with agents:** workflow design, coordination, review, and the engineer's role.
- **Context and reliability:** context limits, compaction, tools, and keeping a task on track.
- **Provider tradeoffs:** model capabilities, subscriptions, pricing, and rate limits.

:::warning[Discussions reflect the time of recording]
Many episodes are several months old. Their discussions of context, coordination, and reviewing AI-generated work remain useful, but RepoPrompt and the surrounding AI tools have advanced substantially since those conversations. Episode titles identify the topic being discussed. Product names, prices, and opinions reflect the time of recording; use the current documentation when making a setup or provider choice.
:::
