Fireworks AI supplies direct API model access for supported RepoPrompt features. Configure its credential in [API Providers → Fireworks AI](../settings/models-and-providers/api-providers.mdx#fireworks-ai), validate it, and inspect the discovered model choices.

## Models and capabilities

Use the [Fireworks model library](https://fireworks.ai/models) to investigate available models. Selection in RepoPrompt depends on what the connected API account and serving configuration expose. A published library entry does not automatically establish access through every account or endpoint.

Choose a model suitable for the intended feature and confirm its actual limits. [Models](./models.mdx) explains the shared availability and identifier concepts. Keep the exact selection with the connection instead of copying an assumed model default into workflow instructions.

## Account and billing

The Fireworks account, selected model, and serving option determine usage charges. Consult [Fireworks pricing](https://fireworks.ai/pricing) and the account's billing controls for current terms. A subscription or credential from another AI provider does not supply allowance for this API route.

The settings page owns the field and button descriptions for validation, discovered choices, changing a credential, and deleting it. An empty model list should be investigated through that connection rather than treated as a complete statement of the provider's public catalog.
