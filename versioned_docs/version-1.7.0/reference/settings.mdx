Open Settings with `⌘+,` or from the gear icon. Use this directory to reach the detailed guide for each settings page. Those guides document the controls and their behavior.

Use [Search Settings](../settings/search-settings.mdx) to find an option by name. For supported integrations, account requirements, model availability, and capabilities, use [Providers & Models](../providers/overview.mdx).

## Agent Mode

- [Overview](../settings/agent-mode/overview.mdx): general Agent Mode behavior and supervision.
- [CLI Providers](../settings/agent-mode/cli-providers.mdx): connect and configure coding runtimes.
- [Agent Models](../settings/agent-mode/agent-models.mdx): model choices for agent roles and supporting tasks.
- [Agent Permissions](../settings/agent-mode/agent-permissions.mdx): direct-agent and sub-agent permissions.
- [Agent Workflows](../settings/agent-mode/agent-workflows.mdx): workflow behavior and related controls.
- [Agent Decisions](../settings/agent-mode/agent-decisions.mdx): automatic routing, effort selection, usage balancing, and decision services.
- [Context Builder](../settings/agent-mode/context-builder.mdx): discovery and context-generation settings.

## General Settings

- [Appearance](../settings/general/appearance.mdx): interface appearance and text presentation.
- [Updates](../settings/general/updates.mdx): update checks and release channels.
- [Notifications](../settings/general/notifications.mdx): notification preferences.
- [Keyboard Shortcuts](../settings/general/keyboard-shortcuts.mdx): configurable shortcuts.
- [Advanced](../settings/general/advanced.mdx): advanced preferences, including the URL Opener.
- [Telemetry](../settings/general/telemetry.mdx): crash-report and diagnostic controls.

## Scripting settings

A subset of preferences is available through MCP and `rpce-cli`. Use the [App Settings Tool](../mcp-server/mcp-app-settings.mdx) for the authoritative allowlist and the [Setup Guide](../mcp-server/mcp-setup.mdx#terminal-access) for terminal access. A control being visible in Settings does not mean it is available through that tool.
