## Manual Download and Installation

1. RepoPrompt is a native macOS application available for [download via our repository](https://github.com/repoprompt/repoprompt-ce/releases). Grab the latest `.dmg` file there.
2. Open the downloaded file
3. Drag the RepoPrompt app to your Applications folder
4. Eject the disk image
5. Open RepoPrompt from Applications or Spotlight

## Homebrew Installation

You can install the pre-built RepoPrompt macOS binaries via Homebrew:

```bash
brew tap repoprompt/repoprompt-ce
brew trust --tap repoprompt/repoprompt-ce
brew install --cask repoprompt-ce
```

## Updates

When automatic checks are enabled and the updater is configured, RepoPrompt checks for updates in the background. You can also check manually through **Settings → General → Updates**. See [Software Updates](../settings/general/updates.mdx).

## Platform Availability

The documented RepoPrompt desktop app is macOS-only. Open-source portability work does not itself establish an official release for another platform. See [Does RepoPrompt Run on Windows or Linux?](../faq/windows-linux.mdx).

## Installing Tip Build

Tip Builds are official signed and notarized builds from the latest successful protected `main` commit. They offer development changes before the next Stable release. To install one, open RepoPrompt and go to **Settings → General → Updates**. Set **Update Channel** to **Tip Builds**, choose **Check for Updates**, and follow the updater's installation prompts when an eligible build is offered. If you have not installed RepoPrompt yet, install and launch the current Stable app using the instructions above, then select the Tip Builds channel.

The selected channel controls which updates the app offers. To return to Stable, change **Update Channel** back to **Stable**. This may require waiting for a newer Stable release; to return immediately, reinstall the Stable application. See [Software Updates](../settings/general/updates.mdx) for more about update checks and channel behavior.

For the tradeoff between channels, see [What Is the Tip Version and Should I Use It?](../faq/tip-version.mdx).

If you want to compile the development source yourself, see [Build Tip code with Xcode](../faq/how-to-build.mdx#build-tip-code-with-xcode). A local Xcode build uses the contributor workflow and is separate from the official signed Tip distribution.
