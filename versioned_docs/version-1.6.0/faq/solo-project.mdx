RepoPrompt began as a solo project, but the Classic answer “RepoPrompt is currently a solo project” does not describe Community Edition's maintenance model. CE is developed through the community repository, where maintainers review contributions and the project records its participation rules.

The founder's [transition announcement](/blog/repo-prompt-next-chapter/) explains the move away from daily stewardship. The [Community Edition announcement](/blog/repo-prompt-community-edition/) identifies the open-source repository as the active development home and invites community participation.

## Where should I go for help?

Use the [application repository](https://github.com/repoprompt/repoprompt-ce) for application behavior, source builds, and feature proposals. Documentation corrections belong with the documentation project. Read [Issue Reporting](./report-issue.mdx) before submitting, including the application's contributor-approval policy.

Support is community-based, with no guaranteed response time. See [the paid-version FAQ](./paid-version.mdx) for what the transition announcement says about licensing and subscriptions.

## Can I participate?

Yes, subject to the relevant repository's contribution rules. See [How Can I Contribute?](./contributing.mdx) for focused ways to help and the difference between application and documentation contributions. Maintainer roles and contributor approval are governed by the project, rather than a permanent team-size claim in this FAQ.
