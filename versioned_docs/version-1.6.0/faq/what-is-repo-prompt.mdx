RepoPrompt Community Edition is a free, open-source macOS app for preparing code context and coordinating coding agents. It combines repository tools, context selection, coding sessions, and model consultations in a shared interface.

## What problem does it solve?

An AI coding harness needs relevant code and clear instructions to work effectively. RepoPrompt helps assemble that context from files, Code Maps, selected line ranges, repository structure, and Git changes. Context Builder can discover relevant code; Oracle can reason over prepared context for plans, reviews, and answers.

You can run supported coding runtimes inside RepoPrompt, connect an external MCP client, or [copy prepared context](../sessions/context-composer.mdx) into another model. The available features depend on the connections and permissions you configure. Context preparation improves what the receiving model can inspect; it does not guarantee a correct answer or implementation.

## Is it a model or a subscription?

RepoPrompt CE is the application and tooling, not an included hosted model allowance. You connect the relevant coding-runtime account, API service, or local model server. See [Providers & Models](../providers/overview.mdx) and [AI Service Costs](./pay-for-services.mdx).

## Is Community Edition the same as Classic?

No. Classic is the archived application and documentation. CE is the active community codebase, with a different interface and emphasis on coding-agent workflows. Some context-engineering concepts carry over, but a Classic screenshot, XML-editing workflow, or preset is not proof that the same feature exists in CE.

Start with [Getting Started](../overview/getting-started.mdx), or use [Sessions & Interface](../sessions/overview.mdx) to learn the controls. For the transition from the former paid product, see [What Happened to the Paid Version?](./paid-version.mdx).
