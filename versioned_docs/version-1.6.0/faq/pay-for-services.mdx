RepoPrompt Community Edition is free and open source. The cost of using an AI model depends on how you connect to it: API billing, a provider's subscription or account plan, or local compute.

## What RepoPrompt charges

RepoPrompt CE does not charge for the application and does not add a markup to provider bills. You supply your own provider account or local model service. The provider's terms, prices, quotas, and data practices apply to requests sent through that service. A provider account or API key may require billing to be enabled even when a provider advertises a free quota.

## Supported AI providers

The source code's **API Providers** settings currently contains **10 direct API or local provider configurations**:

1. Anthropic
2. OpenAI
3. DeepSeek
4. Fireworks AI
5. Grok (xAI)
6. Groq
7. Z.AI
8. Gemini (Google)
9. Azure OpenAI
10. Ollama or LM Studio (local model servers)

OpenRouter and custom OpenAI-compatible endpoints are configured on their own settings pages, so they are separate from that count. Agent Mode's CLI integrations—such as Claude Code, Codex, OpenCode, and Cursor—are also configured separately under **CLI Providers**. They are not API providers, and their subscription or account terms are not the same as API token billing.

### Provider setup and current model catalogs

Provider model catalogs and availability change frequently. The app combines its built-in model catalog with models it can discover from a connected provider; what is selectable depends on the integration, account, region, deployment, and provider API. A model listed by a provider is not necessarily available to every RepoPrompt connection or account. Check the provider's live catalog before choosing a model, and use the model ID shown by the provider when a custom model ID is needed.

RepoPrompt also supports two separately configured routes:

- **OpenRouter** uses an OpenRouter API key and a selectable set of fetched models. Its [model API](https://openrouter.ai/docs/api/api-reference/models/get-models) is the live source for model IDs, context, modalities, and prices. Your OpenRouter account and selected route determine the bill.
- **Custom API** connects to an OpenAI-compatible API endpoint using its base URL, API key, and optional preferred model ID. The endpoint operator determines model availability, billing, privacy, and retention.

For step-by-step connection instructions, see [API Providers](/docs/settings/api-providers/), [OpenRouter](/docs/settings/openrouter/), and [Custom API](/docs/settings/custom-api/).

## How to keep costs predictable

- Review the provider's current pricing and account billing controls before sending requests. Provider pricing, free quotas, and subscription entitlements change; RepoPrompt cannot guarantee any provider's free tier or price.
- Choose a model that fits the task, and keep context focused. Longer prompts and conversations can increase usage-based costs.
- In settings, use provider-side model selection and the app's model and context controls where available. Some workflows can make multiple model requests, so one action may not equal one billable request.
- For local inference, use a model served by Ollama or LM Studio and account for the hardware and electricity costs. A local model avoids a hosted model API bill only when the request actually stays local.
- Check usage and limits in the provider account that owns the API key. RepoPrompt does not control third-party quotas, rate limits, or billing alerts.

## What is free and what is not

The application itself is free. AI use is free only when the particular provider, account, model, and usage are free under the provider's current terms, or when you run the model locally. Subscription access to an agent CLI does not automatically pay for API requests made with a provider API key; likewise, an API key does not automatically include the provider's separate subscription products.
