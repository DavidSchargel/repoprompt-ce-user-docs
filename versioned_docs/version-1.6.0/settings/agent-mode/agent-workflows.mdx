Manage the built-in workflows shown in Agent Mode, featured workflows, custom Markdown workflows, and cleanup guidance included with workflows.

</div>

</div>

Open **Settings → Agent Mode → Agent Workflows**.

1. Under the built-in workflows, toggle **Visible** to show or hide a workflow in Agent Mode. Use its feature control to place a visible workflow among the featured choices shown first.
2. To add a custom workflow, click **New Workflow**, enter a name, and click **Create**. Alternatively, click **Clone** on a built-in workflow, enter a new name, and click **Clone**. Edit the resulting Markdown file in the Workflows folder; **Open Folder in Finder** opens that folder.
3. Under **Prompt Behavior**, toggle **Include Session Cleanup Guidance** to control whether built-in workflows end with instructions to dismiss completed agent sessions. This setting does not change custom workflows or external slash skills.

Select your workflow from the **Workflow** dropdown in Agent Mode before sending a task. These options are separate from [Workflow Presets](../prompting/workflow-presets.mdx) used for Copy/Chat.
