# Getting help

Start with the [RepoPrompt documentation](https://repoprompt.com).

## Documentation and website issues

Open an issue in this repository for unclear instructions, missing explanations,
broken links, incorrect screenshots, or website display problems. Include:

- The page URL or source file.
- What you expected and what happened.
- The RepoPrompt version when the problem concerns an app workflow.
- Browser and operating system details for a website problem.
- A screenshot or minimal example with private information removed, if helpful.

For corrections you can make directly, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Application help and feature requests

Use the [RepoPrompt CE application repository](https://github.com/repoprompt/repoprompt-ce)
for crashes, app behavior, source builds, and application feature requests. Read
its contribution guidance before opening an issue; its participation rules are
separate from this documentation repository.

## Sensitive reports

Follow [SECURITY.md](SECURITY.md) for vulnerabilities or exposed secrets.
Never post credentials or private project content in a public issue.

Support is community-based. There is no guaranteed response time. The Classic
2.1.0 documentation is preserved for reference and may describe obsolete
features, providers, or workflows.
