## Better context, more deliberate changes

Repo Prompt brings context curation and coding-agent orchestration together. Use Context Builder to discover the files relevant to your task, CodeMaps to understand their structure, and reviewable handoffs to separate investigation from implementation.

- **Curate dense context.** Select the code that matters instead of overwhelming the model with unrelated files.
- **Connect your tools.** Use MCP and CLI agent integrations to bring repository context into your workflow.
- **Keep changes reviewable.** Run deep analysis and coordinate agent work while staying in control of the result.
