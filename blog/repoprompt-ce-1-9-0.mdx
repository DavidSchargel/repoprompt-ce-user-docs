**RepoPrompt Community Edition 1.9 is here!**

If you work with several coding agents at once, you know how quickly the conversations can pile up. Which agent is waiting on you? Which one was checking another agent's work? And where did that prompt go when you switched sessions?

This release makes those everyday moments easier to navigate. It also brings improvements to workspace recovery, indexing, and provider sessions.

## Find the conversation you need

The Agent sidebar has a new layout that makes it easier to see your sessions and how they relate to one another. Overseen sessions can appear under their overseer, and an Overseer badge can take you directly to the related conversation.

Use **All**, **Active**, **Pinned**, and **Overseers** to narrow the list. When a parent has a lot of sub-agent threads underneath it, you can collapse those groups and open them again when you need the details.

If you've ever had a handful of agents researching, implementing, and reviewing different pieces of the same task, this should make it easier to find the right conversation and get back to work. Take a look at the [Agent Sidebar Overview](/docs/agent-mode/agent-sidebar-overview/) for the controls.

## See when Claude Code starts a turn

Claude Code can start a turn on its own. In 1.9, those turns show up as ordinary agent runs, so you can follow their activity and use the usual run controls. You don't have to wonder whether something is happening just because you didn't send a new message from the composer.

## Switch sessions without losing a rewrite

Re-prompt helps turn a rough request into a clearer brief before it reaches your coding agent. It now uses the session title and, when enabled, recent conversation context to help with that rewrite.

Need to check another agent while it's working? Go ahead. The rewrite continues while you switch sessions, and you can return to review it. If you've enabled automatic sending, RepoPrompt waits for the correct composer and checks the draft and destination before sending.

There's also a little less friction when you return to a session: RepoPrompt focuses a pending question when appropriate, or the composer, while preserving text you're already typing. Return is kept away from pending approvals, so you can read the card and make that decision deliberately.

See [Re-Prompter](/docs/agent-mode/re-prompter/) for the modes, keyboard controls, and what gets shared with the rewriting provider.

## A safer way back when workspace data can't be read

Workspace recovery is one of those things you hope you never need. When you do, preserving the original data matters.

RepoPrompt now requires a verified recovery backup before replacing unreadable workspace data. If it can't save that backup, it blocks the save and tells you that your latest changes are only in the current window. After addressing the reported issue, you can retry. Compose tabs are also decoded individually, so one unreadable tab doesn't have to take down the whole collection.

The MCP tools enablement preference is now restored per window. Individual tool switches remain shared across windows. See [Manage Workspaces](/docs/settings/manage-workspaces/) and [MCP Tools](/docs/settings/tools/) for more detail.

## The smaller fixes add up

Code Map pause settings now persist for each root. Indexing, bootstrap, and headless connection waits have limits and report errors when they can't finish, giving you a clearer indication of what needs attention.

This release also improves Codex compaction, model menu consistency, and Claude context-window handling. Mixed right-to-left and left-to-right Markdown lists and tables render better, completed Oracle responses can show their duration, and there are fixes for settings scrolling, tooltip sizing, and Debug profile persistence.

## Give 1.9 a try

Open a workspace with a few active sessions and try the new sidebar filters. If you use an overseer, follow its linked sessions and see how the new layout fits the way you work.
